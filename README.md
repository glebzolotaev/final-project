# Планировщик задач (final-project)

Дипломный проект курса Go-разработки: веб-приложение для управления списком
задач с поддержкой повторяющихся событий. Пользователь добавляет задачи с
заголовком, комментарием, датой исполнения и правилом повторения; сервер хранит
их в базе данных SQLite, отмечает выполненные, перенося периодические задачи
на дату следующего выполнения, и удаляет одноразовые.

## Возможности

- добавление, просмотр, редактирование и удаление задач;
- список ближайших задач (до 50 записей) с сортировкой по дате;
- поиск задач по подстроке в заголовке или комментарии;
- поиск задач на конкретную дату (формат `02.01.2006`);
- правила повторения: ежедневно (`d`), ежегодно (`y`), по дням недели (`w`),
  по дням месяца (`m`);
- отметка о выполнении: одноразовые задачи удаляются, периодические
  переносятся на дату следующего выполнения;
- аутентификация по паролю через JWT-токен (при заданной переменной окружения
  `TODO_PASSWORD`).

## Выполненные задания повышенной сложности

- правила повторения `w` (дни недели) и `m` (дни месяца);
- поиск по подстроке и по дате через параметр `search` у `/api/tasks`;
- аутентификация по паролю с JWT-токеном и middleware для защищённых API-запросов;
- сборка докер-образа (multi-stage) и запуск контейнера с базой данных на хосте.
